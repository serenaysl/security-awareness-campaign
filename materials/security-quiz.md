# Security Awareness Quiz

This quiz is based on the topics covered during the awareness campaign.

## Questions

### 1. You receive an email from a familiar company, but the sender address has one letter different from the normal address. What would you do first?

A. Open the link because the company name looks familiar  
B. Check the sender address and verify the message before doing anything  
C. Reply and ask for more links  
D. Download the attachment to see what it contains  

### 2. You use the same password for your personal email and a work account. What is the main problem with this?

A. The password may become too long  
B. If one account is compromised, the other account may also be at risk  
C. The accounts will automatically be locked  
D. MFA will stop working  

### 3. A coworker sends you a message saying they urgently need the verification code that just arrived on your phone. What should you do?

A. Send the code because they are a coworker  
B. Share only half of the code  
C. Do not share it and verify the request another way  
D. Post the code in the team chat  

### 4. An email says, "Your account will be deleted in 10 minutes unless you confirm it now." What makes this message suspicious?

A. It creates pressure and asks for immediate action  
B. It contains a time  
C. It mentions an account  
D. It was sent during working hours  

### 5. Before opening an unexpected attachment from someone you know, what is the safer action?

A. Open it because you recognize the person's name  
B. Verify with the sender that they really sent it  
C. Rename the file first  
D. Forward it to another coworker  

### 6. Which option is a better password habit?

A. Using one password for every account  
B. Using short passwords that are easy to remember  
C. Using unique passwords or passphrases for important accounts  
D. Writing all passwords in a public document  

### 7. Someone calls and says they are from technical support. They ask for your password to fix an urgent problem. What type of risk does this situation represent?

A. Social engineering  
B. Software update  
C. Network monitoring  
D. Data backup  

### 8. You are not sure whether a message is legitimate. What is the safest next step?

A. Click the link and check what happens  
B. Ignore every future message from that sender  
C. Verify the request using a trusted contact method and report it if necessary  
D. Send the message to people outside the company  

## Answer Key

1. B
2. B
3. C
4. A
5. B
6. C
7. A
8. C

## Result Guide

- 7-8 correct: Good understanding of the campaign topics
- 5-6 correct: Review the topics that were unclear
- 0-4 correct: Go through the awareness materials again before retaking the quiz
