# Password Security

Passwords are one of the first lines of defense for online accounts.

Using weak or repeated passwords can make it easier for attackers to access multiple accounts.

## Good Password Practices

- Use a different password for each important account
- Use long passwords or passphrases
- Avoid common words and easy patterns
- Do not reuse work passwords on personal accounts
- Do not share passwords with other people
- Use a password manager if available

## Multi-Factor Authentication

Multi-factor authentication, or MFA, adds an extra security step when signing in.

For example, an account may require:

- A password
- A code from an authenticator app
- A security key
- Another approved verification method

Even if a password is stolen, MFA can make account access more difficult for an attacker.

## Example

Weak password:

password123

Better example:

Coffee-River-Window-27

A longer passphrase is usually easier to remember and harder to guess than a short simple password.

## What Should You Do?

If you think your password may have been exposed:

1. Change the password.
2. Do not reuse the same password on another account.
3. Enable MFA if it is available.
4. Report the issue if it involves a work account.

## Key Message

Use unique passwords and enable MFA when possible.
