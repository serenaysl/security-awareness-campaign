# Phishing Awareness

Phishing is a common cyber attack where an attacker tries to trick someone into clicking a malicious link, opening a dangerous attachment or sharing sensitive information.

## Common Warning Signs

Some phishing messages may include:

- Urgent or threatening language
- Unexpected password reset requests
- Suspicious links
- Unexpected attachments
- Requests for passwords or account information
- Sender addresses that look slightly different from the real company address

## Before Clicking a Link

Before opening a link:

- Check who sent the message
- Hover over the link and inspect the destination
- Look for spelling mistakes or unusual wording
- Be careful with messages that create panic or urgency
- If unsure, open the official website manually instead of using the link

## Example

Suspicious message:

"Your account will be disabled today. Click here immediately to verify your password."

This message should be treated carefully because it creates urgency and asks the user to take an immediate action.

## What Should You Do?

If you receive a suspicious email:

1. Do not click the link.
2. Do not open unexpected attachments.
3. Do not reply with sensitive information.
4. Verify the request using a trusted communication method.
5. Report the message if it looks suspicious.

## Key Message

Think before you click.

A few seconds of checking can prevent a security incident.
