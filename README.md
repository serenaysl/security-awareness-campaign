# Security Awareness Campaign

This project is a basic cybersecurity awareness campaign created to help team members understand common security risks and safer everyday habits.

The campaign is called:

Think Before You Click

## Campaign Topics

The campaign focuses on:

- Phishing awareness
- Password security
- Multi-factor authentication
- Social engineering
- Suspicious links and attachments
- Reporting suspicious activity

## Campaign Structure

The campaign is planned as a one-week awareness activity.

Each day focuses on a short security topic so the information is easier to understand and remember.

The full campaign plan is available in:

campaign/campaign-plan.md

## Campaign Goal

The goal is to help team members recognize suspicious activity before taking action.

The main message is:

Think before you click.

## Evaluation

At the end of the campaign, team members can complete the short quiz included in the project.

The quiz covers the main topics from the campaign and can be used to check basic understanding.

## What I Learned

This project helped me understand why user awareness is an important part of cybersecurity.

Technical security controls are important, but users also need to recognize phishing, protect their accounts and verify suspicious requests.

Creating the campaign helped me think about how security information can be explained in a simple way to people without a technical background.
